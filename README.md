## 📌 Overview

An AI-powered social media automation workflow built using **n8n, Google Sheets, Google Gemini, and LinkedIn**. The workflow connects spreadsheet data, AI-powered content processing, and LinkedIn publishing to streamline repetitive social media tasks.

## ✨ Key Features

- ⚡ **Workflow Automation:** Connect multiple services through n8n.
- 📊 **Google Sheets Integration:** Trigger the workflow using spreadsheet data.
- 🧠 **AI-Powered Content Generation:** Process and generate content using Google Gemini.
- 🔗 **LinkedIn Integration:** Create posts using a configured LinkedIn account.
- 🔄 **Time-Saving Workflow:** Reduce repetitive manual content creation tasks.

| LinkedIn | Social media post creation |

## 🔄 How It Works

1. **Trigger:** Google Sheets initiates the workflow when its configured trigger conditions are met.
2. **Process:** Article information is summarized or processed.
3. **Generate:** Google Gemini helps generate or refine content through an AI chain.
4. **Publish:** The LinkedIn node creates a post using the configured account and permissions.

## 🚀 Getting Started

1. Clone or download this repository.
2. Sign in to your n8n account.
3. Import the workflow JSON file from this repository.
4. Configure your Google Sheets, Google Gemini, and LinkedIn credentials inside n8n.
5. Review the node settings and test the workflow with sample data.
6. Publish or activate the workflow after confirming that it works correctly.

## 🔐 Security Best Practices

- Never commit API keys, access tokens, passwords, or private credentials.
- Store credentials securely using n8n's credential management.
- Review exported workflow JSON files before sharing them publicly.
- Use authorized integrations and review generated content before publishing.
